# astro.MAIN

A simple Render-ready website with the route:

`/load/main`

## Run locally

1. Install Node.js.
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm start
```

4. Open:

`http://localhost:3000/load/main`

## Deploy to Render

Create a new Web Service from this project.

- Build Command: `npm install`
- Start Command: `npm start`

Render will provide an `onrender.com` URL.

## Customize

Edit:

`public/index.html`

`public/style.css`
